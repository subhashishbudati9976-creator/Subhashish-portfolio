# Subhashish — Personal Developer Portfolio

A long-term personal portfolio built as an AI-assisted engineering project.

## Goals

- present Subhashish professionally
- create a distinctive dark cinematic visual identity
- demonstrate frontend and product thinking
- integrate a personal AI assistant
- maintain production-minded engineering practices
- fulfill the ShadowFox internship requirements without treating them as the project's ceiling
